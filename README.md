# 全台辦桌王

以臺灣辦桌文化為主題的荒謬物理網頁小遊戲。手機直式（9:16）優先，單手觸控或滑鼠就能玩。四攤關卡各用一種不同的物理機制，玩完再進到「吃席」大結局，最後產生可以分享的迷因結算圖卡。

- 線上試玩：https://cindyguo0214.github.io/banzhuo-king/
- 原始碼：`index.html`（單一檔案，約 5,800 行）

---

## 怎麼開

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝或建置。

- 物理引擎 [Matter.js](https://brm.io/matter-js/) 0.20.0 從 cdnjs 載入，第一次開啟需要連網。
- 載不到時，loading 畫面會顯示「總舖師叫不到菜」，提示重新整理。

---

## 遊戲流程

```
Loading（總舖師炒鍋）
  → 首頁（左半圓扇形選單，中間是辦桌）
    → 點一攤 → 短版 Loading「上菜中」→ 規則卡（時間暫停）→ 按「看懂了，開始！」才計時
      → 結算圖卡（分享／複製文字／再玩一次／回地圖）
        → 「不管啦！先吃再說！」→ 吃席大結局 → 吃席結算 → 「生成今日辦桌戰績」圖卡
```

- 首頁正中間的辦桌也能點，可以直接去吃席。
- 結算後按「再玩一次」會直接開始，不再顯示規則卡和 loading。

## 四攤關卡

| 攤 | 主題 | 核心物理 | 時間／次數 | 過關目標 | 最高評價 |
|---|---|---|---|---|---|
| 1 | 婚宴【紅包塞塞樂】 | 軟體物理（可壓縮紅包）、彈性碰撞 | 50 秒 | NT$38,000 | NT$52,000 |
| 2 | 尾牙【抽獎摸彩大狂飆】 | 風洞氣流、離心力、複合剛體 | 45 秒 | NT$12,000 | NT$60,000 |
| 3 | 普渡【好兄弟搶食大作戰】 | 布娃娃物理（Ragdoll）、堆疊 | 45 秒 | NT$500 | NT$800 |
| 4 | 神明誕辰【擲筊聖燈疊疊樂】 | 不規則剛體、彈跳 | 10 次擲筊，不計時 | 600 點福氣 | 1,500 點或擲出立筊 |

每一攤都有一個「風險量表」，衝到 100% 就會觸發災難收場，該局歸零。

### 第 1 攤：婚宴【紅包塞塞樂】

- **操作**：按住畫面任意處往反方向拉，放手把紅包射進禮金箱的窄投入口。發射器每次會隨機換到左邊或右邊。
- **紅包種類**：每包紅包都是兩排粒子加上彈簧網格組成的軟體，越厚越值錢、越硬、越彈。

  | 名稱 | 金額 |
  |---|---|
  | 薄薄一包 | 1,200 |
  | 標準誠意 | 2,600 |
  | 很有誠意 | 3,600 |
  | 六六大順 | 6,600 |
  | 磚塊等級 | 12,000 |

- **壓力量表**：由四部分組成：箱內面積填充率、堆疊高度、紅包被壓扁的程度、箱內的晃動程度。紅包卡在投入口時會額外加壓。
- **災難收場**：壓力超過 100% 持續 0.35 秒，就會「紅包火山爆發」：箱蓋飛走、紅包噴飛、鈔票像噴泉一樣湧出，禮金歸零。
- **封箱交差**：覺得夠了可以按這顆按鈕提早收工。
- **硬要親自塞的長輩賓客**：開局約 7～9 秒後第一次出現，之後每 9～13 秒一次（剩 5 秒內不會再來）。阿伯、阿姨或二叔公的手從畫面左右伸進來，頭上有對白預告，約 1 秒後伸到投入口，擠來擠去 1.5～2.1 秒，手是實體，會占掉半邊洞口。
  - 還沒進箱的紅包碰到手會被**整包撞飛**，已經在箱內的不受影響。
  - 手離開時會丟下一包自己的紅包（1,200～3,600），真的會落進箱子：禮金增加，壓力也跟著上升，可能把快滿的箱子撐爆。
  - 結算會統計「被長輩撞飛幾包」。

### 第 2 攤：尾牙【抽獎摸彩大狂飆】

- **操作**：在畫面任何地方拖曳，用「相對位移」移動手，手指不會擋住手。點一下＝握拳抓球，再點一下＝放手。
- **得獎方式**：把拳頭整個拉出頂部洞口，手上的球就算中獎，舞台上方會廣播「恭喜 ○○部 ○○ 抽中…」。
- **獎項**（公司與人名皆為虛構）：

  | 獎項 | 內容 | 數量 |
  |---|---|---|
  | 頭獎 | 現金 88,888 | 1 顆，球又小又滑 |
  | 二獎 | 機車一台（50,000） | 1 顆 |
  | 三獎 | 氣炸鍋（6,000） | 3 顆 |
  | 四獎 | 禮券（2,000） | 5 顆 |
  | 普獎 | 衛生紙一串（200） | 10 顆 |
  | 銘謝惠顧 | 老闆的擁抱 | 10 顆 |

- **物理**：底部風扇往上吹，加上旋轉氣流，偶爾還會有「強風加碼」。抓到的球會和手合成同一個複合剛體，抓越多拳頭越寬，會真的卡在洞口，要扭一扭才轉得出來。手晃太快，球會從拳頭滑掉。
- **晃動量表**：硬拉卡住的手、撞到箱壁、在箱裡亂揮都會讓晃動上升。
- **突然蓋上黑布**：開局約 9～12 秒後第一次，之後每 9～13 秒一次（剩 5 秒內不會再來）。主持人喊話預告 0.8 秒，黑布蓋下來約 3.6 秒，看不到箱內的球和手，只有淡淡的鼓包能猜位置，還是可以照常抓球。蓋著時中獎會顯示「摸黑中獎！」，圖卡短評也會提到。摸彩箱翻倒時黑布會掀掉。
- **災難收場**：晃動到 100% 時摸彩箱翻倒，彩球滾滿地，獎品全部作廢。

### 第 3 攤：普渡【好兄弟搶食大作戰】

- **角色**：圓滾滾的白色好兄弟，由身體、兩節小短手和三節飄飄尾巴組成，是布娃娃物理。飄浮力比重力小一點，所以永遠東倒西歪。自己的好兄弟頭上綁著三角頭巾。
- **操作**：按住畫面，好兄弟會醉醺醺地飄向手指，雙手往手指伸，碰到供品就自動抓住，放手供品就掉下去。
- **得分方式**：把供品拖回左下角的「冥府外送袋」才算分。

  | 供品 | 數量 | 價值 |
  |---|---|---|
  | 罐頭（4-3-2-1 罐頭塔） | 10 罐 | 每罐 45 |
  | 旺來 | 2 顆 | 每顆 80 |
  | 泡麵 | 3 包 | 每包 25 |
  | 烤雞 | 1 隻 | 350，很重，要兩隻手 |

- **隔壁好兄弟**：淡紫色、吐舌頭，大約每 10～13 秒從右邊飄進來搶供品。它會先「聞聞～」約 1.3 秒才下手，這段時間可以去搶。兩邊同時抓住同一樣東西就會拔河。
- **阿嬤怒氣**：供品被撞飛（例如罐頭塔倒了）、掉到地上都會讓阿嬤生氣，她會從右下角探頭。
- **災難收場**：怒氣到 100% 時阿嬤撒鹽米，好兄弟被轟走。

### 第 4 攤：神明誕辰【擲筊聖燈疊疊樂】

- **次數制**：這攤不倒數，總共可以擲 10 次。每次要等筊杯停穩、結果顯示完才能擲下一次，上方資訊列顯示「剩 N 次」。10 次擲完、最後一次的結果演完才結算。
- **操作**：往要丟的方向拖曳，拖越長越大力，放手擲出兩個筊杯。力道箭頭會從綠變黃再變紅，旁邊標示「剛好／有點大／太猛」。
- **物理**：每個筊杯都是半月形剛體，一面平（原木色）、一面凸（紅漆）。落地停穩後，才依朝上的面判定結果。地毯中間有一道門檻，撞到會亂彈。

  | 結果 | 判定 | 福氣 |
  |---|---|---|
  | 聖筊 | 一平一凸 | 100 × 連續次數，三連聖筊再 +300 |
  | 笑筊 | 兩平 | +20 |
  | 陰筊 | 兩凸 | 0 |
  | 立筊 | 筊杯站著停住 | +1,000，滿屏金光，約 1.3% |
  | 桌底筊 | 滾進神桌底下 | 0，廟公火氣 +15 |

- **光明燈**：每個聖筊點亮一盞光明燈（共 21 盞），立筊一次點亮 5 盞。
- **神明造型**：神桌後方是男性的 Q 版財神爺，造型比照結算圖卡的插圖：紅金官帽配雲形帽翅和珠串流蘇、瞇眼笑、八字鬍加長黑鬚、紅金官袍、雙手合十。
- **廟公火氣**：太大力撞到神桌或燭台、燭台倒掉、筊杯滾進桌底，都會讓廟公生氣。
- **災難收場**：火氣到 100% 時廟公拿掃把衝出來，把你請出去。

## 大結局：不管啦！先吃再說！【吃席大作戰】

俯視一張紅色大圓桌，中間有轉盤，周圍坐了 7 個人，坐誰看你從哪一攤來（見下方「同桌的人」）。限時 20 秒。

### 桌上吃什麼，看前四攤的成績

每一攤最近一次的評價會被記錄下來（這次開網頁玩的優先，其次是瀏覽器存的紀錄）：

- 每攤的分數：最高評價 3 分、過關 2 分、失敗 1 分、災難收場 0 分。
- 玩過的攤平均達到滿分的一半以上，就是**滿漢全席（豪華版）**；否則是**克難版**。一攤都沒玩過也是克難版。

| 版本 | 桌上內容 | 吃席目標 |
|---|---|---|
| 滿漢全席 | 佛跳牆，加上炸雞翅、紅蟳、大蝦、鮑魚、滷蛋、香腸冷盤、湯圓、東坡肉，共 20 樣 | 300 分 |
| 克難版 | 9 根骨頭、半碗白飯、兩根青菜、一個蝦頭，缺角灰盤、空鍋配蒼蠅 | 20 分 |

### 夾菜操作

1. 手指按住就能移動筷子，筷子尖在手指上方一點點。
2. 筷子碰到盤子就會**自動鎖定**那道菜：菜外圍出現金色虛線光圈，筷子跟著轉盤一起移動。手指拉開太遠會解除鎖定。
3. 按住時下方「力道」條會來回跳，放手的瞬間決定結果。結果只看力道，沒有隱藏的運氣：
   - **綠色區（38%～78%）**：一定夾到，菜飛進自己的碗。
   - **太小力**：滑掉，會顯示當時的力道百分比。
   - **太大力**：菜彈飛出去，多半飛向最近的親戚。
   - 親戚大力轉轉盤時，綠色區會變窄成 47%～67%，力道條上會提示「轉盤轉很快！」。
4. 被砸中的人會晃一下，冒出表情符號和自己的台詞（例如三姑「我要跟你媽講！」），還有「啵～」加「啪」的音效。沒砸到人的菜會「飛到隔壁桌了！」。
5. 鎖定的菜如果先被別人夾走，會顯示「被○○搶先了！」。

吃席坐哪一桌，看你**剛玩完的那一攤**（從結算畫面按「不管啦！先吃再說！」進來）。從首頁中間的辦桌直接進來，就坐最後玩過的那一攤；從來沒玩過就坐婚宴桌。桌巾中間的大字也會跟著換。

|---|---|---|---|
| 婚宴 | 婚宴親友桌 | 囍 | 二叔公、三姑、表哥、新郎爸爸、鄰居阿姨、小表弟、里長伯 |

每一桌的 7 個人對應同樣 7 種搶菜風格，但名字、表情、筷子顏色和台詞都是那一桌自己的（例如尾牙的直屬主管「這個我先 review」、普渡的骷髏哥「骨頭輕，飄得快」、廟口的乩童「神明指示：那盤！」）：

|---|---|---|---|
| 只挑最貴的 | 挑桌上分數最高的菜（紅蟳、鮑魚優先） | 1.1 秒，最慢 | 二叔公「這尾要給阿公補一下」 |
| 一次夾兩道打包 | 一次夾走兩道 | 0.8 秒 | 三姑「這個我打包給孫仔」 |

| 會幫你夾菜 | 六成機率把菜夾進**你的碗**（算你的分） | 0.7 秒 | 鄰居阿姨「多吃一點啦！」 |

- 大約每 1.8～3 秒會有一個人出筷，頭上冒出招牌台詞。筷子伸到之前把菜搶走，會顯示「搶贏○○！」，對方也會回一句不甘心的話。

- 實測：一直穩定夾菜的話，一局大約被夾走 3～6 道。
- 結算評語會點名「最會搶的是○○」，有人幫你夾菜也會寫出來。

## 分享圖卡：台式手繪認證卡

四攤各自的結算圖卡，和吃席的「今日辦桌戰績」，都用同一套 1080×1440 版型（`buildShareCard(spec)`），只靠設定切換內容。

**版面（由上到下，參考使用者提供的範例圖）**：米白紙底，沒有外框。
1. 左上品牌小標＋小圓桌圖示：四攤是「全台辦桌王｜第 N 攤・○○鑑定」，吃席是「全台辦桌王｜吃席人格鑑定」。
2. 大稱號：靠左、深朱紅粗黑體，是整張最大的字，兩側有芥末黃放射線。
3. 兩行梗圖金句：靠左、墨黑粗體。
4. 右上角兩顆紅燈籠，加一個紅底白字的角色對白泡泡（例如「你怎麼都沒吃！」）。
5. 滿版插圖：來自 `result-img` 資料夾，下緣被一條微微拱起的紙面弧線收掉。
6. 插畫右下角一個歪斜的紅色標語章，兩行各四字（例如「禮貌有餘／戰力不足」）。
7. 三欄大數字：細紅線分隔，標籤在上、深朱紅大數字配單位；下面一行主資訊、一行灰色次要資訊。
8. 只有「今日辦桌戰績」有五枚圓形徽章：紅包、摸彩箱、戴皇冠的雞腿、燈籠、白飯碗，下面寫各攤最近一次的評價；沒玩過的徽章變淡，寫「還沒去吃」。單攤卡沒有徽章，插畫拉高。
9. 左下兩行粗體短評＋灰色 `#全台辦桌王`；右下紅線分隔，寫「不服？換你坐這桌。」「掃碼挑戰」，配箭頭指向白底 QR 框。

**插圖依實際結果切換**（共 40 張，對應表在 `embed-result-img.py` 的 `ART`）

| 卡片 | 張數 | 怎麼選 |
|---|---|---|
| 四攤 | 16 | 每攤四張，對應最高評價、過關、失敗、災難收場 |
| 吃席 | 24 | 六種稱號 × 四種桌別，依畫面上的角色對應（不是看檔名尾碼） |

神明誕辰的最高評價有兩種情況：擲出立筊時用立筊圖；沒擲出立筊、靠分數達標時，因為沒有專屬圖，用聖筊圖。

**換圖**：改 `result-img` 的檔案或 `ART` 對應後，執行 `python embed-result-img.py`（需要 Pillow）。圖片會縮成 1080 寬的 WebP，內嵌在 `index.html` 最後的 `<script id="card-art">`（`window.CARD_ART`），所以 `index.html` 約 4.2 MB。內嵌是為了維持單檔，而且直接開檔案時匯出 PNG 也不會被瀏覽器擋。

插圖原本是 3:2，版面放不下全高，所以上下會裁掉一些：`cardSpec()` 裡的 `artTop` 決定從幾 % 高度開始顯示（吃席 12%、掃盤王 7%、四攤 5%），下緣被紙面蓋住。程式畫的場景（`CARD_LEVEL_ART`、`CARD_FEAST_PROPS`）還留著，只有插圖解碼失敗時才會用到。

**統計來源**：每一攤的 `finish()` 會額外回傳 `card`（四攤用 `levelCardData()`，吃席用 `feastCardData()`），只讀當局狀態，不改成績。

| 攤 | 三格戰績 | 次要資訊 |
|---|---|---|
| 婚宴 | 收到禮金（爆發時改「噴出禮金」）／塞進箱子／最高壓力 | 目標金額・掉在地上幾包 |
| 尾牙 | 抽中獎金（翻倒時改「作廢獎金」）／抽中獎項／最高晃動 | 目標金額・最大獎 |
| 普渡 | 搶到供品（撒鹽時改「被打掉的供品」）／被隔壁搶走／阿嬤怒氣 | 目標金額・搶到幾件・最值錢 |
| 神明誕辰 | 福氣／聖筊／光明燈 | 擲了幾次・立筊・廟公火氣 |
| 吃席 | 吃到／被親戚（尾牙是同事、其他桌是同桌）夾走／砸中同桌 | 吃席分數・桌別；搶贏・夾滑・滿漢全席或克難版 |

**產生流程**

- 結算當下把資料凍結成 `result.card`，之後只讀它，等字型或 QR 時就算開了下一局也不會被蓋掉；開新局時進行中的圖卡會作廢。
- 匯出前先等粗黑體字型（Google Fonts 的 Noto Sans TC，最多等 3 秒，網路差就用系統黑體）。
- 紙紋和抖動用由成績算出的固定種子，同一局重畫結果一樣。
- 長文字都用 `measureText` 縮字或換行（稱號、金句、徽章、短評、數字）。
- 預覽、分享、剪貼簿用同一張 canvas。

**QR Code 與 `SHARE_URL`**

- 設定位置：`index.html` 裡圖卡區塊開頭的 `let SHARE_URL`。
- 目前設定為 GitHub Pages 網址 `https://cindyguo0214.github.io/banzhuo-king/`。留空時，QR 區會顯示虛線框「網址待設定」，不產生假的碼。
- 設定後用 qrcode-generator 1.4.4（cdnjs）在瀏覽器本地產生，容錯等級 M，整數像素模組，四周至少 4 模組白邊；網址不會送到任何 QR 圖片服務。函式庫載入失敗時顯示「QR 產生失敗」。
- 已驗證：設定測試網址後，從畫面上的 canvas 和匯出的 PNG 都能用 jsQR 解回同一個網址。

**改文案的位置**：吃席金句 `CARD_COPY[稱號][桌別]`；四攤金句 `LEVEL_COPY[攤][評價]`（神明誕辰另有 `li` 立筊句）；標語章 `CARD_TAGS`、`LEVEL_TAGS`；對白泡泡 `CARD_SAY`、`LEVEL_SAY`；版面位置 `CARD_LAYOUT`；四攤短評保底句 `LEVEL_ROAST`；吃席短評 `cardRoast()`；四攤統計欄位 `LEVEL_SPEC`；備用的程式場景 `CARD_LEVEL_ART`、`CARD_FEAST_PROPS`、角色外型 `CARD_LOOKS`。

## 介面與共用功能

- **Loading 畫面**：紅白辦桌棚、閃爍燈泡、炒鍋上翻飛的食材、火焰和蒸氣、進度條，以及每 1.4 秒換一句的辦桌梗（例如「塑膠椅疊到第 38 張了…」）。點炒鍋可以幫忙翻炒，翻越多下總舖師的評語越多。最少顯示 1.6 秒。

- **規則卡**：每攤開始前顯示玩法和目標，時間先不倒數。
- **分享圖卡**：見下一節。
- **分享**：
  - 手機上優先叫出系統分享選單。
  - 其次把圖片寫入剪貼簿。
  - 在內嵌頁面（例如分享連結）中，這兩種都會被擋，會提示「長按上方圖卡即可儲存分享」。

- **音效與回饋**：全部用 WebAudio 即時合成（振盪器加濾波白噪音），不需要音檔。右下角可以靜音，靜音時也不震動。

## 技術架構

### 技術組成

- 單一 HTML 檔，純 HTML / CSS / JavaScript，沒有框架也沒有建置步驟。
- Matter.js 0.20.0 負責所有物理。
- 畫面是 Canvas 2D；選單扇形用 SVG，Loading、規則卡、結算面板用 DOM。

### 座標與縮放

- 遊戲固定用 540×960 的邏輯座標（9:16）。
- `resize()` 依螢幕等比縮放 `#app`，並設定 CSS 變數 `--u`（1 邏輯像素），DOM 介面都用 `calc(var(--u)*N)` 排版。

### 物理迴圈

- 固定步長 120Hz（`STEP = 1000/120`），每個畫面最多跑 5 步，降低穿牆。
- 速度單位沿用 Matter 0.20 的「每 16.67ms 位移」。

### 關卡模組介面

共用核心負責計時、上方資訊列、結算、圖卡、分享、選單和輸入分派。每一攤是一個物件（`L1`～`L5`，登記在 `LEVELS`），提供：

| 欄位／方法 | 用途 |
|---|---|
| `id, venue, name, time, target, god` | 基本設定；`time` 設 0 就不倒數（擲筊改用 `throwsMax` 次數，`hud()` 回傳 `left` 顯示剩餘次數） |
| `intro` | 規則卡內容：`icon`、`rules`、`goal`（L5 是 getter，依成績動態產生） |
| `grades` | 各評價的 `{ title, stamp }` |
| `snap` | 結算當下截一張遊戲畫面的裁切範圍（分享圖卡已改用手繪插畫，目前沒有用到這張截圖） |
| `setup(g)` | 建立該攤的物理世界與狀態 |
| `beforeStep()` | 每個物理子步前呼叫（風力、浮力、手的速度控制…） |
| `onCollision(e)` | 選用，碰撞事件 |
| `update(dt)` | 每個畫面的遊戲邏輯 |
| `shakeLevel()` | 依風險值決定畫面震動 |
| `drawBackground()` / `drawScene()` / `hud()` | 繪圖與上方資訊列內容 |
| `pointerDown/Move/Up(p, e)` | 輸入，`p` 是邏輯座標 |
| `finish(reason)` | 回傳 `{ grade, final, comment, money, stats, shareMoney, card }`；`card` 是分享圖卡的凍結資料 |
| `afterEnd()` | 選用，自訂結算流程（L5 先出吃席結算面板） |

災難收場統一呼叫 `crash(reason, title, sub)`：先演出 2.8 秒，再進入結算。

### 常改的數值在哪裡

| 想調整 | 位置 |
|---|---|
| 紅包種類、金額、硬度 | `TYPES` |
| 婚宴壓力公式 | `updateEnvelopes()` 裡的 `raw` |
| 摸彩箱尺寸、獎項 | `JAR`、`PRIZES` |
| 婚宴長輩賓客（人物、台詞、手的大小速度、出現頻率） | `L1_GUESTS`、`L1_ARM`、`l1GuestUpdate()` |
| 尾牙風力、卡住與晃動 | `L2.beforeStep()`、`L2.update()` |
| 尾牙黑布（各階段秒數、出現頻率） | `L2_CLOTH`、`l2ClothUpdate()` |
| 普渡供品、好兄弟大小 | `FOODS`、`GHOST_S` |
| 筊杯形狀、結果與分數 | `BLOCK`、`RESULTS`、`l4Judge()` |
| 吃席時間、菜色、力道區間 | `FEAST_TIME`、`FEAST_FOODS`、`POWER_OK`、`POWER_SPIN` |
| 各桌同桌的人、風格、速度、台詞 | `CASTS`（每桌 `table`、`mark`、`guests` 的 `style`、`reach`、`go/got/miss/hit`…）、`SEAT_DEG`、`feastRob()`、`feastRobLand()` |
| 音效 | `sfx()` 裡的 `RICH`（噪音型）與 `P`（單音）；震動 `buzz()`；火花 `burst()` |
| 擲筊次數 | `L4.throwsMax` |
| Loading 小提示 | loader 腳本裡的 `BASE_TIPS`、`LOAD_TIPS` |

### 測試掛勾

頁面上有 `window.__bzk`，可以在 DevTools 裡呼叫：

- `__bzk.startLevel(id, intro)`：直接開某一攤
- `__bzk.tick(秒)`：同步快轉物理與邏輯，不受畫面更新率影響
- `__bzk.render()`：手動畫一幀
- 各攤的輔助函式，例如 `launch`、`l2ToggleGrip`、`l4Throw`、`feastClamp`
- 圖卡（開發用，不影響正常流程）：`__bzk.buildShareCard(__bzk.cardSpec(資料))` 產生任意結果的圖卡；`__bzk.levelCardData(LEVELS[id], 評價, 數字)` 造四攤資料；`__bzk.setShareUrl(網址)` 暫時設定網址測 QR；`__bzk.cardCanvas` 是目前顯示的圖卡

開發時就是用這些掛勾寫自動測試機器人，來調整平衡數值。

### 發佈

線上版用 GitHub Pages，直接發佈 repo 根目錄的 `index.html`，push 到 `main` 後會自動更新。`result-img` 原圖沒有放進 repo，換圖要在有原圖的電腦上執行 `embed-result-img.py`。

## 已知限制與待確認

- 目前只在電腦瀏覽器的手機尺寸模擬（375×812）下測試，**還沒在真的手機上玩過**。觸控手感、力道條的時機、各攤難度都需要實機確認。
- 系統分享、圖片寫入剪貼簿在不同手機與瀏覽器上的支援不同，都不支援時會改成下載圖檔。
- 瀏覽器分頁切到背景時畫面會暫停，切回來會繼續。
- 遊戲中出現的公司名稱「旺旺來科技」、各種人名和角色都是虛構的。
- 遊戲畫面的美術用 Canvas、SVG 和 emoji 即時繪製；結算圖卡的插圖來自 `result-img`，內嵌在 `index.html`。分享圖卡另外從 Google Fonts 載入 Noto Sans TC，從 cdnjs 載入 qrcode-generator。
- 分享圖卡還沒在真的手機上確認：系統分享選單、LINE／IG 預覽裁切、從手機螢幕掃 QR 的距離都需要實機測。
